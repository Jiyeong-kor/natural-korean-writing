# Application Answer Workflow

Read this entire index, then read the stage references required for the current role and task. All roles follow the entrypoint's required context and punctuation guidance. Writers and substantive reviewers also read the [application prose profile](profile-application.md). Keep working records private unless the user requests them. These are decisions tied to the actual application, not headings to paste into every answer. All examples in the linked stage references are fictional.

## Required reading by task

| Current task | Required references |
| --- | --- |
| Coordinate the work without drafting or judging the content | Follow the [agent workflow](agent-workflow.md) and this index. Delegate writing and substantive review. Before taking over either activity, read every reference required for that role below. |
| Draft an application answer, substantively revise it, or perform an independent review | Read [planning and evidence](application-planning.md), [writing and reader fit](application-writing.md), and [review and version freeze](application-review.md) in full. All three are required for both the writer and the independent reviewer. |
| Prepare or substantively assess a recommendation about whether to apply for a role | Read the same three references. Apply the [recommendation evidence checks](application-planning.md#ground-application-recommendations-in-role-evidence) to the current official role and the applicant's own evidence, and complete any required suitability review before recommending application. |
| Perform authorized form or application-template work | Add [form work](application-form-work.md) when that work is part of the task. If the work also drafts, substantively revises, or reviews an answer, read the three core references above. |
| Package requested submission originals or report their download state | Add [original delivery](application-delivery.md) when that work is part of the task. If the work also changes or reviews an answer, apply the core reading requirements above. |

The writer and independent reviewer must not omit a core stage based on their role name. The writer must establish the question-to-evidence and duty-to-evidence connections before drafting, then verify their passages in the current answer. The independent reviewer must examine the same source evidence, considered candidates, actual passages, and complete same-company answer set; the writer's summary or verdict does not replace that work. Missing evidence remains a stated limit rather than a passed check.

Read the form and original-delivery references only when those actions are in scope. A writing or review assignment does not by itself authorize form entry, saving, uploading, downloading, or submission. Preserve the current action-specific authorization and completion states.
